# Continuity Decision Tree

```text
START
│
├── Is the subject the same biological individual?
│   ├── yes → check memory continuity
│   └── no  → check derivative or emergent status
│
├── Is autobiographical memory preserved?
│   ├── yes → check autonomy continuity
│   ├── suppressed/fragmented → fractured
│   └── not inherited → derivative or emergent
│
├── Is autonomy preserved?
│   ├── yes → continuous or partial
│   ├── restricted → disputed
│   └── command dominated → blocked review
│
├── Is there emergent memory or personality?
│   ├── yes → emergent new identity
│   └── no  → derivative not continuous
│
└── Are fields sealed?
    └── yes → sealed review
```

## Archive Rule

```text
High lineage similarity is not identity continuity.
Low autonomy is not low moral value.
Suppressed memory is not absence of self.
```
