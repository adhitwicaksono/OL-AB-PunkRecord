# Trait Insertion

```text
NODE : 04_engineering_pipeline_records/trait_insertion
TYPE : target trait and marker insertion records
LINK : lineage_factor_repository + phenotype_ability_archive
```

This subnode records which traits were targeted, which markers were involved, how expression was recorded, and which ethics gate was triggered.

It does not provide editing instructions.

## Main Files

```text
trait_insertion_events.csv
trait_insertion_rules.yaml
off_target_warning_table.tsv
```

## Archive Warning

```text
Trait expression is not pipeline success unless off-target risk, subject status, and consent are also recorded.
```
