The **Engineering Pipeline Records** node documents how subject records move from biological origin into derivative bodies, engineered units, converted platforms, ability carriers, and command-responsive systems.

This node does not provide executable wet-lab instructions.

It records the administrative, biological, and ethical metadata needed to trace what happened to a subject after the archive stopped calling them only a subject and started calling them an output.
