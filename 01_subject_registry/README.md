The **Subject Registry** stores biological origin, template relationships, intervention class, deployment status, autonomy level, identity continuity, and review warnings.

A subject record is never only a body.

A subject record may contain:

```text
origin + template + modification + memory + autonomy + risk + unresolved identity claim
```

## Registry Classes

```text
01 original_subjects
02 clone_derived_subjects
03 engineered_units
04 cyborg_converted_subjects
05 unidentified_biological_entities
```

## Core Rule

```text
same template does not mean same person
same body does not mean same autonomy
same function does not mean same moral status
```

## Fast Index

| Registry folder | Main file | Purpose |
|---|---|---|
| `original_subjects/` | `original_subjects_index.csv` | Baseline subjects and donor templates |
| `clone_derived_subjects/` | `clone_derived_subjects_index.csv` | Clone-derived individuals and template relationships |
| `engineered_units/` | `engineered_units_index.csv` | Designed units with inserted traits or ability systems |
| `cyborg_converted_subjects/` | `cyborg_converted_subjects_index.csv` | Subjects with biological-mechanical integration |
| `unidentified_biological_entities/` | `unidentified_entities_index.csv` | Unknown or unstable biological records |
