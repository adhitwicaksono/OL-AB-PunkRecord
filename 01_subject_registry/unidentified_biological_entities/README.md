# Unidentified Biological Entities

```text
NODE : 01_subject_registry/unidentified_biological_entities
TYPE : unstable, incomplete, anomalous, or unregistered records
ALERT: classification failure may hide risk
```

Unidentified biological entities are records that cannot be confidently assigned to original, clone-derived, engineered, or cyborg-converted categories.

Some are incomplete.
Some are sealed.
Some are byproducts.
Some may be new subjects emerging from systems that were never meant to produce life.
