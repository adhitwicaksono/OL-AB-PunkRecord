# Clone-Derived Subjects

```text
NODE : 01_subject_registry/clone_derived_subjects
TYPE : template-derived biological records
ALERT: genetic similarity is not personal continuity
```

Clone-derived subjects are generated from original templates but are not identity copies.

## Main Table

```text
clone_derived_subjects_index.csv
```

## Registry Logic

```text
template_source identifies biological origin
memory_status identifies personal continuity risk
autonomy_score identifies command restriction
identity_continuity must never be inferred from sequence alone
```

## Archive Rule

```text
A clone may inherit sequence.
A clone does not inherit a life.
```
