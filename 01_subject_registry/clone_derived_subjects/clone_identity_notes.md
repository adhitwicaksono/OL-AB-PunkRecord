# Clone Identity Notes

## Identity Layers

```text
genetic template     : inherited or copied biological sequence
developmental route  : growth history, environment, intervention
memory state         : inherited, not inherited, suppressed, developing, unknown
autonomy state       : independent, restricted, command-dominated
social identity      : name, history, recognition, rights
```

## Registry Warning

```text
same genome       → not same memory
same template     → not same person
same appearance   → not same autonomy
same command role → not same consent
```
