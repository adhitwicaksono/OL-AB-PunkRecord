# Original Subjects

```text
NODE : 01_subject_registry/original_subjects
TYPE : baseline biological records
LINK : lineage_factor_repository + neural_identity_log + ethics_risk_monitor
```

Original subjects are baseline biological records used to compare templates, variants, traits, intervention histories, and identity continuity.

These records are not neutral.

A baseline can become a donor.
A donor can become a template.
A template can become a weapon.
A weapon can still point back to a person.
