The **Lineage Factor Repository** stores sequence-like records, variant profiles, donor-template metadata, trait-associated markers, and compatibility indices.

This node does not claim that life is reducible to sequence.

Instead, it tracks the biological instruction layer that experimental pipelines repeatedly attempt to read, copy, modify, transfer, and weaponize.

## Repository Classes

```text
01 sequence_records
02 variant_profiles
03 donor_template_metadata
04 trait_associated_markers
05 compatibility_indices
```

## Core Rule

```text
sequence can describe inheritance
sequence can support engineering
sequence can reveal similarity

but sequence alone cannot define personhood
```

## Fast Index

| Repository folder | Main file | Purpose |
|---|---|---|
| `sequence_records/` | `lineage_factor_sequences.fasta` | FASTA-style lineage-factor records |
| `variant_profiles/` | `lineage_factor_variants.vcf` | Variant-like differences and annotation tags |
| `donor_template_metadata/` | `donor_template_metadata.csv` | Donor-template links and derivative-use metadata |
| `trait_associated_markers/` | `trait_marker_catalog.csv` | Marker-to-trait annotation records |
| `compatibility_indices/` | `compatibility_scores.csv` | Template-to-intervention compatibility estimates |

## Repository Warning

```text
A sequence can be copied.
A lineage can be indexed.
A trait can be annotated.

But a life cannot be fully compressed into a FASTA header.
```
