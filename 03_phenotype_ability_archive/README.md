The **Phenotype & Ability Archive** connects subject records and lineage-factor markers to visible traits, artificial ability classes, body-state alteration events, transfer histories, and plausibility classification.

This node is where sequence claims meet the body.

A marker is not enough.

A body must be observed.

A trait must be measured.

An ability must be classified.

A transfer event must be traced.

A plausibility boundary must be declared.

## Fast Index

| Archive folder | Main file | Purpose |
|---|---|---|
| `observed_traits/` | `observed_traits_index.csv` | Trait observations linked to subject records |
| `artificial_abilities/` | `ability_registry.csv` | Artificial ability classes, effects, and biological analogies |
| `body_state_alteration/` | `body_state_events.csv` | Body-form, material, tissue, and state changes |
| `transfer_events/` | `ability_transfer_events.csv` | Ability carrier, transfer, replication, and failure events |
| `plausibility_classification/` | `plausibility_matrix.csv` | Biological plausibility tiers and classifier rules |
