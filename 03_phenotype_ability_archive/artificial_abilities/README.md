# Artificial Abilities

```text
NODE : 03_phenotype_ability_archive/artificial_abilities
TYPE : ability registry and class definitions
LINK : lineage_factor_repository + body_state_alteration + transfer_events
```

Artificial ability records describe observed or transferred ability-like phenotypes, their effect class, required body system, biological analogy, plausibility class, and risk flag.

## Main Files

```text
ability_registry.csv
ability_classes.tsv
ability_class_rules.yaml
```

## Archive Instruction

```text
Do not collapse all abilities into mutation.
Do not treat ability transfer as ordinary inheritance.
Do not treat spectacular effects as explained mechanisms.
```
