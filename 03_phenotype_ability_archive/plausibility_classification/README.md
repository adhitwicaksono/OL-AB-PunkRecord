# Plausibility Classification

```text
NODE : 03_phenotype_ability_archive/plausibility_classification
TYPE : biological plausibility and review routing
LINK : artificial_abilities + body_state_alteration + transfer_events
```

Plausibility classification separates observed effect, proposed mechanism, biological constraint, and review route.

## Main Files

```text
plausibility_matrix.csv
plausibility_classifier_rules.yaml
classification_report_template.md
```

## Classification Tiers

```text
plausible      : compatible with known biological principles
speculative    : partly grounded but requires major unknowns
boundary_case  : touches biology but exceeds current mechanism
impossible     : outside biological mechanism
unresolved     : insufficient, sealed, or corrupted evidence
```

## Warning

```text
Impossible does not mean unrecorded.
Unresolved does not mean ignored.
Boundary case does not mean approved.
```
