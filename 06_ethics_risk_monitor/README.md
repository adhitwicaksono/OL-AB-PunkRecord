The **Ethics & Risk Monitor** records consent status, military deployment, juvenile subject flags, autonomy restriction, reversibility status, and personhood conflict.

This node is not an accessory to the archive.

It is the firewall.

It exists because the other nodes can describe sequence, phenotype, engineering, and identity, but none of those records can answer the final question alone:

```text
Should this have been done?
```

## Core Rule

```text
technical success does not cancel consent failure
military value does not cancel subject status
restricted autonomy increases protection requirement
irreversibility increases review burden
personhood conflict must not be administratively erased
```
